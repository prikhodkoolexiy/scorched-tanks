# Scorched Tanks

Артиллерийская игра в духе Scorched Earth и Pocket Tanks: до 10 танков, ИИ трёх уровней, 5 ландшафтов, 9 видов оружия, 3 вида щитов, езда за очки, магазин между раундами.

**Играть:** откройте страницу игры на GitHub Pages (ссылка в описании репозитория) в Safari или Chrome на компьютере. Нужна клавиатура.

## Игра с друзьями

### Без сервера (по ссылке)
1. Откройте игру по ссылке, вкладка «Онлайн по приглашению», «Создать комнату».
2. Нажмите «Копировать» и отправьте ссылку друзьям.
3. Друг открывает ссылку, вводит имя и нажимает «Войти».
4. Хост выбирает число танков (свободные места займёт ИИ) и нажимает «Начать игру».

Соединение идёт напрямую между браузерами (WebRTC, сигнальный сервер PeerJS). В некоторых корпоративных и мобильных сетях прямое соединение не проходит, тогда используйте вариант с сервером.

### Через свой сервер на Mac
Дважды кликните `start.command`. Нужен Node.js или Python 3. Если установлен Tailscale, скрипт включит Tailscale Funnel и даст публичную ссылку `https://….ts.net`; при первом запуске Tailscale попросит включить Funnel по ссылке.

## Управление
| Клавиша | Действие |
|---|---|
| ← → | угол |
| ↑ ↓ | сила (Shift точнее) |
| Пробел | выстрел |
| Tab | оружие и щиты |
| S | поставить щит (держится 2 круга) |
| A / D | ехать (1 очко за 4 px, до 100 px за ход) |
| Esc | меню: переиграть или пропустить раунд |
| M | звук |

## Файлы
- `index.html` — вся игра в одном файле
- `server.py` / `server.js` — сервер комнат без зависимостей
- `start.command` — запуск сервера на macOS
